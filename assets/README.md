# Assets

Drop these PNG files in here before running `expo start`:

- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive icon (foreground only)
- `splash.png` — 1284×2778 launch screen
- `favicon.png` — 48×48 web favicon

Until you do, Expo will use a placeholder icon. The build will still run.
